## 📝 Опис реалізації
*Коротко опишіть, що саме було зроблено в рамках цього завдання. Яку логіку ви реалізували, які підходи використали?*

**Приклад:**
У цьому завданні реалізовано базовий вивід повідомлення "Hello Embedded World!" у UART. Налаштовано швидкість порту через макрос `UART_SPEED` (який прокидається з `platformio.ini`).

## 💻 Логи терміналу / Скріншоти
*Деякі завдання (особливо де є робота з сенсорами, логуванням або RTOS) вимагають доказів роботи у вигляді логів терміналу. Вставте їх сюди.*

**Приклад логу:**
```text
[00:00:00.010] Hello Embedded World!
[00:00:01.010] LED ON
[00:00:02.010] LED OFF
```

*Також сюди можна додавати скріншоти (наприклад, графіки з логічного аналізатора).*
